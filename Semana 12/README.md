# Reserva de Asientos en Sala de Cine

## Nombre del Estudiante
**Randolph Wong**

## Objetivo del Programa
Desarrollar un programa en Python que simule la reserva de asientos en una sala de cine pequeña (3 filas x 4 columnas). El programa utiliza una matriz bidimensional (lista de listas) para representar el estado de la sala, donde 0 indica un asiento libre y 1 un asiento reservado. El usuario podrá ingresar la fila y columna para reservar un asiento, y el programa mostrará el estado final de la sala utilizando bucles anidados.

## Cómo Ejecutarlo

### Pasos para la ejecución
1. Descarga o clona este repositorio en tu computadora.
2. Abre una terminal o consola de comandos en la carpeta donde guardaste el archivo.
3. Ejecuta en **python reserva_cine.py**
